# Purge swap-proxy from animaksm

## Summary
Remove the entire `crates/swap-proxy` crate, its config knobs (`[swap_proxy]` TOML section + `SwapProxyConfig` struct + `AnimaksmConfig.swap_proxy` field + all swap-proxy validation), the `SwapProxyError` variant in `error.rs`, the workspace member entry in `Cargo.toml`, the `[swap_proxy]` section in `config/animaksm.toml`, the `systemd/animaksm-swap-proxy.service` unit, and all user-facing mentions in `README.md` + `AGENTS.md` structure comment.

After deletion: run `cargo build --workspace` and `make check` to confirm clean compile.

---

## Files to delete (recursive)

1. `crates/swap-proxy/` (entire directory, ~100k of Rust: `main.rs`, `backend.rs`, `dedup.rs`, `fingerprint.rs`, `ublk_frontend.rs`, `Cargo.toml`)
2. `systemd/animaksm-swap-proxy.service`
